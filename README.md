# 4-Track Studio

Multi-track audio recorder with mixing, effects, and WAV export.

## Features
- **4 Independent Tracks**: Record, playback, and mix 4 separate tracks
- **Low Latency**: Optimized for real-time recording with minimal delay
- **Per-Track Controls**: Volume, pan, mute, solo, arm for recording
- **Track Effects**: EQ, Reverb, Delay, Compressor per track
- **Master Section**: Master volume, compressor, output metering
- **Transport Controls**: Play, pause, stop, rewind, loop
- **Real-time Meters**: Visual level meters for all tracks
- **WAV Export**: Mix down and download as WAV file
- **Microphone Input**: Direct recording from device microphone

## Usage
1. Click the **R** button on a track to arm it for recording
2. Press **Record** (red button) to start recording
3. Press **Play** to playback all tracks
4. Use **Export WAV** to save your mix

## Requirements
- Android 5.0+ (API 21+)
- Microphone permission
